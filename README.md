# 🩺 Multi-Label Classification of Thoracic Diseases using Chest X-Rays

This repository contains a comprehensive pipeline for detecting multiple thoracic diseases from chest X-rays using both deep learning (CNNs) and traditional machine learning (Random Forest, XGBoost). The core model is built on *DenseNet121* with *ImageNet or CheXNet pretrained weights*, depending on the phase of the pipeline.

---

## 📁 Repository Overview

| File | Description |
|------|-------------|
| ⁠ Custom_CNN.ipynb ⁠ | 🔥 *Main notebook* for model training. Uses DenseNet121 (with ImageNet weights) as backbone to train on chest X-rays. Includes preprocessing, training with Focal Loss, threshold tuning, evaluation, and plot generation. Saves final model weights and metrics. |
| ⁠ Feature_extractor.ipynb ⁠ | 🧠 Extracts features from chest X-rays using DenseNet121 pretrained with *CheXNet weights*. Outputs a CSV file with 1025 columns (1 ⁠ Image Index ⁠ + 1024 extracted features). |
| ⁠ processed_data.ipynb ⁠ | 🔄 Applies augmentation to handle class imbalance using two strategies: *1) MLSMOTE, **2) Centroid-Based Augmentation*. Helps to oversample rare disease classes for improved downstream training. |
| ⁠ RandomForest.ipynb ⁠ | 🌲 Trains a Random Forest classifier using the augmented feature dataset generated by ⁠ Feature_extractor.ipynb ⁠ + ⁠ processed_data.ipynb ⁠. |
| ⁠ XGBoost.ipynb ⁠ | 🚀 Trains an XGBoost model on the same augmented features and compares its performance. |

---

## 📌 Workflow Summary

### Step 1: Deep Learning Approach (Custom CNN)

•⁠  ⁠*Input*: X-ray images from ⁠ IMAGE_FOLDER ⁠ and a CSV file with labels
•⁠  ⁠*Model*: DenseNet121 (ImageNet weights)
•⁠  ⁠*Loss*: Focal Loss
•⁠  ⁠*Output*:
  - Trained model weights (⁠ .pth ⁠)
  - Evaluation metrics (CSV)
  - ROC and PR curve plots (PNG)

### Step 2: Feature Extraction

•⁠  ⁠*Input*: NIH ChestX-ray14 images (download required)
•⁠  ⁠*Model*: DenseNet121 with CheXNet pretrained weights
•⁠  ⁠*Output*: Feature CSV with 1025 columns per image

### Step 3: Data Augmentation

•⁠  ⁠*Augmentation Methods*:
  - MLSMOTE
  - Centroid-based synthetic samples
•⁠  ⁠*Output*: Augmented feature dataset with improved label distribution

### Step 4: Traditional ML Models

•⁠  ⁠*Models Used*:
  - Random Forest (⁠ RandomForest.ipynb ⁠)
  - XGBoost (⁠ XGBoost.ipynb ⁠)
•⁠  ⁠*Input*: Augmented feature CSV
•⁠  ⁠*Output*: Classification metrics per disease
